知隙 Glance v1.1.0：更紧凑的浮窗与更流畅的操作。

- 待机420×116 DIP，查询按需展开到420×280 DIP；清空后自动恢复紧凑输入栏。
- 移除口号与大块留白，保留输入、回答和必要操作；支持340×196 DIP的紧凑回答布局。
- 网络解析移至后台；首段立即安排显示，后续约33毫秒合并刷新，长文本分批显示。
- 费用预留/结算、历史保存、设置保存和导出在后台执行。
- 历史后台加载、120毫秒搜索防抖、可见行复用、缓存刷新与搜索结果过期保护。
- 历史窗口与设置窗口同步缩小，继续支持缩放与滚动。
- 17项测试通过，新增8000段流式数据和5000条历史的桌面回归检查。

继续使用已有本机设置、加密Key、历史与费用账本。下载Glance.exe后替换旧版本即可。

默认Ctrl+Alt+Space唤起，Enter查询，Esc收起。费用规则及未签名发行文件说明见README。界面联调使用本机模拟服务。
