知隙 · Glance 首个 Windows 桌面版本。

下载 `Glance.exe` 后双击运行，在设置中填写自己的 DeepSeek API Key。

- Ctrl+Alt+Space 唤起，Enter 查询，Esc 收起。
- 默认 DeepSeek Flash、非思考、单轮、流式回答；支持停止与托盘驻留。
- 本机历史搜索、回顾、复用、删除，Markdown/JSON 导出。
- API Key、接口、模型、快捷键与统一高级设置，保存后生效。
- 单次/每日/每月费用边界，独立持久化账本。
- Key 使用 Windows DPAPI 当前用户加密。
- 自带 .NET 运行时的 Windows x64 单文件 EXE。

费用按用户配置的单价在本机估算，服务账单以供应商记录为准。停止或缺少用量回执时保留全额预留。详细规则见 README。
